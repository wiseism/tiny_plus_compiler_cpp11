# 实验背景与内容概览

看不出具体是哪所大学。文档只写了讲义作者“魏建双”“李林杰”和教室编号，没有校名；我也没找到可信公开来源能将这套 TINY+ 实验准确归属到某所学校，所以不宜猜测。

这是一个典型的《编译原理》课程实验，围绕自定义的 TINY+ 语言，主要包括：

- 词法分析：手写扫描器、Token 分类、最长匹配、字符串/注释/非法字符报错。
- 语法分析：EBNF 文法、递归下降分析、抽象语法树；README 的“预测分析”属于可扩展项。
- 语义分析：符号表、重复声明/未声明变量、类型检查、条件表达式检查。
- 中间代码生成：三地址码、临时变量、标签、`if`、`while`、`repeat` 的跳转与短路逻辑。
- 选做内容：函数定义、参数表；资料未正式定义函数调用语法。
- 课程最终要求还提到 IDE、源码编辑、运行和汇编代码展示；但仓库目前主要覆盖编译器前端与中间代码。

PPT 里还包含栈式虚拟机/P-Code 的内容，像是后续扩展；实验文档的硬性目标是先生成中间代码。
